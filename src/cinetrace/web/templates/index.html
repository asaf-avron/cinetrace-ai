The Sentinel is given the schema and the goal, not a list of queries. Run the supervisor to capture the run_query calls it composed.

    Root cause

    ASOF LEFT JOIN pairs every OOM failure with the nearest telemetry sample recorded before it died. No other engine expresses "the row just before this moment" in one join, and pulling 235M samples into Python to find it is not an option.

    Have we seen this before?

    Error text is embedded with Vertex AI text-embedding-005; the archive of past incidents lives in ClickHouse and is searched by cosineDistance. It matches meaning, so a description that shares no keywords with the original ticket still finds it.

      Detection layer

      Five deterministic queries over the job_waste view. Thresholds are per-cohort quantileTDigest fences, not constants: a job is an overrun relative to other jobs on the same show and renderer, never at a fixed hour count.
